# Changelog

## 1.1.0

The brief knows what the day is like and what is waiting: it reads the weather
and names the few mails that plainly want an answer today, by sender and
subject. It still cannot answer, move or delete a message. A second run on the
same day now stops instead of writing the day twice.

## 1.0.1

The brief now opens with today's appointments. It reads the calendar and
nothing more: it cannot create, move or delete an entry.

## 1.0.0

First release. A brief written at 07:30 from open tasks, the day's schedule and
saved reminders, stored as one Markdown file per day inside the plugin's own
folder. The page lists the last seven.

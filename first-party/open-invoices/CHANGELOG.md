# Changelog

## 1.0.0

First release. An invoice list kept in one file inside the plugin's folder, with
per-currency totals, a state of not due, due today or overdue by a number of
days, and an inline way to mark one paid or delete it. A weekday morning run
prepares the reminder letters in three escalating stages and notes payment hints
found in recent mail, without ever marking an invoice paid. Sending is the
person's: the page shows each letter, remembers your edits to it, and sends only
behind an approval card that names the recipient and the text.

# Changelog

## 1.0.0

First release. The file half fingerprints a file on this machine with SHA-256
and looks that fingerprint up at VirusTotal, so a private document can be
checked without leaving the machine; the upload that would publish it is a
separate, clearly labelled second press and never happens on its own. The link
half follows a pasted address without opening it and reports where it lands,
what host that is, what stood out about it, and what the page says about itself,
and it needs no key at all. Both halves keep their last ten results here.

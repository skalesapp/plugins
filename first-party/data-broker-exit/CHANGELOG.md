# Changelog

## 1.0.0

First release. The California data broker registry is pulled in and kept as a
file with the date it was fetched, and the page draws all 603 entities with the
sites each one operates. Selecting a company drafts a request in the right
jurisdiction, GDPR Articles 15 and 17 or the California delete and opt-out
sections, carrying only the identifiers you switched on, and sending it stops
at an approval card you press. The deadline is counted from the day the letter
went out, and a weekly run reads the mailbox for replies, drafts follow-ups for
anything overdue, and writes one digest per run. The forms, the demands for an
identity document and the California DROP filing are gathered into one list of
things only a person can do.

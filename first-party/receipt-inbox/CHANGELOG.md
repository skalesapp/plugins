# Changelog

## 1.0.0

First release. An evening run reads the inbox, recognises receipts, invoices and
payment confirmations, and merges them into one ledger keyed by sender and
document number, so the same mail read twice stays one row. The page shows a
month at a time with every cell editable, marks the rows the run was unsure of,
and hands the month on as a CSV or as a mail to the accountant that waits for a
confirmation card.
